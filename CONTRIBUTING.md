# Contributing

Install Bun 1.3.13 and run `bun install`. Use `bun run check` before opening a pull request.
Behavioral changes need automated tests and user-facing API changes need a changelog entry and docs.

PR titles must begin with `Hotfix` or a Linear ticket such as `[ENG-123]`.

Natural follows the Contributor Covenant. Security reports should be sent privately to the
maintainers rather than opened as public issues.
